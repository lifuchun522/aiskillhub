# 结构化配图：卡片类型与版式约束

## 一、11 种卡片

| kind | 结构含义 | 必填字段 | 版式 |
|---|---|---|---|
| `flow` | 流程 / 阶段 / 因果链 | `title`,`items` | 横向节点链，项间连线 |
| `quad` | 一个命题的四宫格分解 | `title`,`items`(4) | 2×2 方阵 |
| `split` | 一个整体向下拆成若干部分 | `title`,`center`,`items` | 中心 + 分支 |
| `compare` | 左右两栏对照 | `title`,`leftTitle`,`left`,`rightTitle`,`right` | 双栏 + 中缝 |
| `map` | 左项逐行映射到右项 | 同 compare | 两列 + 逐行连线 |
| `integrate` | 多来源汇聚成一个结果 | `title`,`inputs`,`output` | 扇形汇聚 |
| `pyramid` | 自下而上分层 | `title`,`items` | 四层梯形（items 由下往上） |
| `relation` | 中心节点与周边要素 | `title`,`center`,`items` | 中心辐射 |
| `stat` | 一个刺眼的数字 | `title`,`value`(,`unit`) | 巨字 + 说明 |
| `quote` | 一句要被记住的话 | `note` | 大字居中 |
| `bullets` | 并列结论 | `title`,`items` | 逐条淡入 |

## 二、字数上限（硬约束，超了必折行出框）

| 位置 | 上限 | 说明 |
|---|---|---|
| `flow` / `pyramid` 节点 | **6 字** | 再长就挤成两行，破坏等距 |
| `quad` / `split` / `relation` / `bullets` 条目 | **13 字** | 单元格宽度决定 |
| `compare` / `map` 单栏条目 | **11 字** | 双栏各占一半 |
| `integrate` 来源 | **12 字** | 扇形区域窄 |
| `center` | 8 字 | 中心圆 |
| `output` | 8 字 | 汇聚点 |
| `title` | 16 字 | 卡片标题 |
| `note` | **27 字** | 底部小注，超过 27 字实际渲染会溢出（实战踩过） |
| `value` | 8 字 | 巨字，含符号 |

`plan_cards.py` 会逐项检查并拒绝生成，不要绕过它。

## 三、项数约束

- `quad`：正好 4 项，少于 4 用 `bullets` 或 `flow`；
- `pyramid`：≤4 层，超过拆成两张；
- `compare`：每栏 ≤4 条，多了观众读不过来；
- `relation`：≤4 个周边，多了改 `split`；
- `flow`：≤6 节点，超过说明该拆成「总览 + 分述」两张。

## 四、选型判断法（按旁白原话选，不按好看选）

问三个问题：

1. 旁白有没有说数量词？
   「分三类」「四个维度」「五个步骤」→ 图上的项数**必须与口播数字一致**，
   口播说三个就画三个。这是最容易被观众抓到的错。
2. 这些项之间是并列、先后，还是层级？
   - 并列 → `split` / `quad` / `bullets`
   - 先后 → `flow`
   - 层级（越往下越硬 / 越往上越稀缺）→ `pyramid`
3. 有没有「之前 vs 之后」「理想 vs 现实」？
   有 → `compare`，左右两栏标题要写成对偶短语（「按理说 / 现实是」）。

## 五、节奏与密度

- 9 分钟片 **20~26 张**，平均 20~25 秒一张；
- 单张不要短于 4 秒（观众来不及看），也不要长于 35 秒（会以为卡住了）；
- 连续两张同类型会显得单调：`flow → flow` 中间插一张 `quote` 或 `stat`；
- 数据类卡片（`stat`）不要连着放超过 2 张，隔一张 `compare` 或 `split` 缓一下；
- 开场 0~8 秒：一张 `quote`（钩子）+ 一张 `compare`（反差）；
- 结尾：`bullets` 收结论，`quote` 落金句，金句要能独立成立、不回看上下文也懂。

## 六、文案写法

- 卡片是**提词板**不是**转录稿**：只留关键词，不写完整句子；
- 同一张卡里句式要齐平（都是动词短语，或都是名词短语），混排会乱；
- `note` 用来放「口播里有但图里放不下的补充」，一句足矣；
- 不要用「等」「等等」结尾，卡片上看到「等」就说明该拆项了；
- 中英混排时英文两侧留空格，`1800 个技能` 而不是 `1800个技能`。
