# 交付前核对清单

按顺序勾，任何一项不通过就不要交付。

## A. 素材与预算（写稿前）

- [ ] 1. PPT 已导出为页图，`prep_slides.py` 报出的页数 **N** 已记录
- [ ] 2. 页图全是 16:9（或已知非 16:9 并接受留边）
- [ ] 3. 已问过用户「有没有配套文章/讲稿」，答案已落定（有→已通读；没有→纯按 PPT）
- [ ] 4. 目标时长已确定：**5 ≤ T ≤ 20**，且口径是「1.2 倍速版」；未指定则 ≤15 分钟
- [ ] 5. `budget.py` 给出字数/段落预算

## B. 讲稿（渲染前）

- [ ] 6. 段落数 = `budget.py` 估出的段数 ±15%，每段 45~70 字
- [ ] 7. 页序与 PPT 完全一致，没有跳页、没有把一页的内容拆成两页讲
- [ ] 8. 封面只讲标题与总纲，不提前讲内容
- [ ] 9. 有文章时：每页至少 1 条 PPT 上没有的例子/判断
- [ ] 10. `budget.py --script` 实测时长落在目标 ±0.3 分钟内

## C. 配音与卡片

- [ ] 11. `narrate.py` 三项自检通过（片头静音、首句有声、时长差 < 0.05s）
- [ ] 12. `plan_cards.py --narrow` 校验通过（无字数超限/重叠/缺字段）
- [ ] 13. 旁白里说的每个「N 个要点」都能在对应卡上数出同样的 N 项

## D. 页时间轴（最容易翻车）

- [ ] 14. `add_slides.py` 的页数断言通过（**起点数 == 页数 == N**）
- [ ] 15. 打印出的「每页首段原文」逐行看过，每页讲的就是那张图
- [ ] 16. `semantic_check.py`：0 个错误；「跨段」清单逐条判断完毕

## E. 渲染

- [ ] 17. 探测片段抽帧看过：左栏卡片完整、右栏是当页图、页码正确、字幕在安全区
- [ ] 18. 分块渲染全部块成功（无 `rc≠0`）
- [ ] 19. `merge_chunks.sh` 后帧数 ≈ 各块之和（块边界丢 1~2 帧/块属正常）
- [ ] 20. 抽 3 个块边界帧，无黑帧、无错页

## F. 交付

- [ ] 21. 两版都出了：`_原速.mp4` + `_1.2倍速.mp4`
- [ ] 22. 响度：`I ∈ -16 ± 0.5 LUFS`；真峰值 `TP ≤ -1.0 dBTP`
- [ ] 23. 时长：**1.2 倍速版在 5~20 分钟之间**（有指定就对齐指定值）
- [ ] 24. 倍速版 srt 已同步压缩，抽 1 条核对时点正确
- [ ] 25. 每页抽 1 帧核过：字幕内容与左栏卡片说的是同一件事

## 常见「看起来过了其实没过」

- 只看了第 0 帧的静态图 → 卡片还没展开，误判成缺项
- 只核了首尾两页 → 中间页错位全漏
- 只测了 wav 响度 → AAC 编码后峰值超标没发现
- 只数了 `--starts` 的逗号 → 手写漏一位，全片歪
