# 例子索引

三份文件，覆盖「照抄格式」「看懂命中」「接上宿主」三件事。

| 文件 | 什么时候看 | 内容 |
|---|---|---|
| [`snapshot-pass.md`](snapshot-pass.md) | 想照抄一份合格快照 | 三个真实场景的完整十二行快照（代码 / 文档 / 短答） |
| [`snapshot-hit.md`](snapshot-hit.md) | 想知道命中长什么样、怎么返工 | 一条命中快照 + 返工前后对照 + 重写后的成品 |
| [`../references/hosts.md`](../references/hosts.md) | 换宿主、规则不生效 | 四个宿主的安装位、常开规则片段、五个接线陷阱 |

---

## 怎么用这些例子

**第一步**，抄格式 —— 打开 `snapshot-pass.md`，照现有十二行的写法填自己的核对内容。格式对了，至少不会被"贴标签式快照"糊弄过去。

**第二步**，抄判据 —— 打开 `snapshot-hit.md`，看同一个句子里「哪半句过关、哪半句命中」。判据在 [`../references/gates.md`](../references/gates.md)。

**第三步**，抄接线 —— 打开 `../references/hosts.md`，把常开规则粘到对应位置。不接这一步，技能只是躺在磁盘上。

---

## 一个最小可用的判断

写完快照后自问一句：

> 如果有人拿这十二行逐条追问我「你到底核对了什么」，我答得出来吗？

答不出来，说明这十二行是标签，不是审计。回去重写。
