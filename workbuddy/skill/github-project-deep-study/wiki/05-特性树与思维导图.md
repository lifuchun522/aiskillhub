# 特性树与思维导图

特性清单用文字表格给，读者记不住。**八域切分 + 一张导图**，一眼看完整个能力版图。

---

## 八域怎么切

八域不是为内容生成类项目定制的，它是**「输入 → 加工 → 产物」流水线**的通用切法。换项目类型时保持"域"的位置不变，换掉域里装的东西。

| 域 | 内容生成类（视频/文章/音频） | 数据处理类（ETL/爬虫/搜索） | 开发工具类（CLI/SDK/框架） |
|---|---|---|---|
| A 输入/生成源 | 文案、LLM Provider | 数据源、连接器 | 配置、插件来源 |
| B 转换/加工 | 配音 TTS | 清洗、转换算子 | 编译/处理管道 |
| C 素材/外部资源 | 视频素材、图库 | 抓取目标、代理池 | 依赖、模板 |
| D 细分处理 | 字幕、ASR | 解析、抽取 | 语法/格式处理 |
| E 增强 | 背景音乐 | 富化、打标 | 扩展、中间件 |
| F 产物/合成 | ffmpeg 渲染 | 输出格式、落地存储 | 产物、打包 |
| G 接口层 | REST / WebUI | API / CLI | CLI / SDK API |
| H 工程特性 | 配置、安全、i18n | 调度、幂等、监控 | 构建、缓存、日志 |

**每域必答三问**：

1. 有哪些选项（枚举完整）
2. 哪些要外部 Key / 付费凭据
3. 本次实测走了哪一条

第三问是分水岭 —— 只写 1、2 是转述 README，写了 3 才是实测。

## 数据格式

导图由脚本从 JSON 生成，不手画：

```json
{
  "title": "特性树 · 思维导图",
  "subtitle": "8 个域 · 条目全部来自源码枚举与界面实测",
  "center": {"title": "项目名", "sub": "特性树 · 8 域", "foot": "v1.0.0 · 实测环境"},
  "domains": [
    {
      "letter": "A",
      "name": "文案生成",
      "sub": "LLM · 37 Provider",
      "needkey": "部分免 Key",
      "color": "#60a5fa",
      "children": ["Provider 注册表 37 项", "ollama 本地免 Key", "手填脚本即跳过调用"]
    }
  ]
}
```

字段约束：

| 字段 | 规则 |
|---|---|
| `needkey` | 只能取 `免 Key` / `部分免 Key` / `需 Key`，决定徽章颜色 |
| `color` | 缺省从内置 10 色盘按序取 |
| `children` | 每条 ≤ 14 个汉字，脚本自动换行；超过 6 条会增高卡片 |
| `sub` | 域副标题，写机制或数量，如 `TTS · 11 类通道` |

## 生成

```bash
python scripts/gen_mindmap.py --data tree.json --out mindmap.svg
# [ok] mindmap.svg | 1800x862 | domains=8 | chars=22232 | theme=dark

python scripts/gen_mindmap.py --data tree.json --out light.svg --theme light --width 2000
```

布局规则（确定性，同一输入永远同一张图）：

- 中心节点在正中，宽 366，两侧留白 96
- 前一半域在左列、后一半在右列，各列垂直居中
- 单侧卡片宽 = `W/2 - 183 - 96 - 40`，自动算
- 子条目按估算字宽换行，CJK 按 1.06em 留余量

想换配色改 `color` 字段；想换主题用 `--theme light`；域多于 8 个用 `--cols`。

## 内联进 HTML

导图必须是**内联 SVG**（矢量、缩放不糊、可 CSS 控制），不能是 `<img src="mindmap.svg">`。

```html
<input type="checkbox" id="mmzoom" class="mmzoom-t">
<label for="mmzoom" class="mmzoom-l">🔍 点击放大查看导图</label>
<div class="mindmap-wrap">
  <svg class="mindmap" ...>...</svg>
</div>
```

三件套必须**同级相邻**，顺序固定 —— `~` 只认兄弟节点，顺序错了或套了层 div 就失效。

```css
.mmzoom-t{position:absolute;left:-9999px;opacity:0;width:1px;height:1px;pointer-events:none}
.mmzoom-l{display:inline-block;cursor:zoom-in;font-size:13px;color:#2b6cb0;
  border:1px solid #c3d7f2;background:#eef4ff;border-radius:999px;padding:6px 14px}
.mmzoom-t:checked ~ .mindmap-wrap{position:fixed;inset:0;z-index:999;margin:0;border-radius:0;
  padding:18px 18px 70px;overflow:auto;background:#0b0f19}
.mmzoom-t:checked ~ .mindmap-wrap .mindmap{min-width:1440px;max-width:none;width:100%}
.mmzoom-t:checked ~ .mmzoom-l{position:fixed;top:14px;right:18px;z-index:1000;cursor:zoom-out;
  background:#1b2742;color:#e8eefc}
```

checkbox 必须**离屏**（`left:-9999px`）。只写 `display:none` 也行，但用 `opacity:0` 保留可访问性。忘了这行会让 checkbox 裸露在页面上 —— 这是改样式时最容易丢的一条。

## 怎么读这张图

导图不是装饰，是决策工具。三个读法：

**1 找免费通道**

绿色条目 = 不需要付费凭据。如果绿的少，说明这项目"不花钱跑不通"，这是重要结论，写进边界思考。

**2 找伪能力**

某域徽章写着"免 Key"，但实测发现所有条目都要联网 —— 要么徽章标错，要么这域是空壳。逐条核，别信标签。

**3 找能力空洞**

八域里如果某域只有 1–2 个条目，说明这块能力薄弱。比如 D 字幕域只有"整句显示"一个选项，就说明它这是最简实现。

## 常见错误

| 错误 | 后果 | 正解 |
|---|---|---|
| children 写成整段话 | chip 换行后卡片极高，图不可读 | 每条压到 ≤ 14 字 |
| 八域硬套，某域空着 | 露出"这域没内容"的信息 | 空的域合并或注明"无此域" |
| 手画 SVG 或截图贴进来 | 改一个条目要重画 | 改 JSON 重跑脚本 |
| 导图不内联，用外部 SVG | 单文件交付破裂 | 内联 |
| 只做导图不做明细 | 读者想查具体配置项无处查 | 导图下加 `<details>` 折叠完整枚举 |

导图负责"看得见全貌"，`<details>` 里放完整枚举负责"查得到细节"。两者都要。
