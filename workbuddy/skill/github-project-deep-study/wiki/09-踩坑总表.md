# 踩坑总表

每一条都在真实项目上踩过并验证过处置方式。**先扫这张表，能省一小时。**

细节与代码见 [`references/pitfalls.md`](../references/pitfalls.md)。

---

## 环境类

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 1 | `pip install` 跑 70 分钟，`site-packages` 只有 2 项 | 默认 PyPI 索引不可达，pip 静默重试 | 换清华镜像，实测 5m47s；装前先用小包验 25 秒 |
| 2 | `rm -rf .venv` 报 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` | 删除文件数超沙箱批量阈值 | 不删，原 venv 内直接装；`pip` 会覆盖 |
| 3 | `rm -f` 9 个文件也触发 SIGTERM | 阈值比文档（50）低 | 删文件 **3–5 个一批**分多条命令 |
| 4 | 长任务带 `\| head -30` 后进程退出码 1 | 管道截断导致 SIGTERM | 重定向到文件或后台跑，不用管道截断 |
| 5 | `dotnet build` 报 "command could not be loaded" | 只有 runtime 没有 SDK（`No SDKs were found`） | 官方 `dotnet-install.ps1 -Channel 10.0 -InstallDir <项目>/.dotnet` |
| 6 | `git clone` 连续 502，但浏览器能开 GitHub | git 隧道不稳 | 走 codeload tarball（不走 git 协议通常仍通）；代价是无 `.git`，commit 从 README 取 |

## 截图类

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 7 | `chromium_headless_shell-1248 not exist` | playwright 库要求的 build 号与本地下载的（1228）不一致 | `executable_path` 指向系统 Edge/Chrome |
| 8 | `screenshot(full_page=True)` 只截一屏 | Streamlit 用内部容器滚动，`body` 高度不代表内容高度 | 视口开到 2800 高，一次装下 |
| 9 | 首屏正中是「第一步：设置 XX」弹窗 | 引导浮层遮挡 | 截图前按 `aria-label="Close"` 关闭，多选择器依次尝试 |
| 10 | `[data-testid="stVerticalBlockBorderWrapper"]` 返回 0 个 | testid 随框架版本变化 | 不依赖 testid，整页大视口 + 按标题 y 坐标裁切 |
| 11 | Swagger 截图只有端点标题行 | 端点默认折叠 | 循环点开 summary 2–3 轮；展开后整页上万像素，用 CSS 限高 |
| 12 | 内嵌图后 HTML 2MB+ | PNG 未压缩 | 量化到 192–256 色，体积降约 60%（42KB→15KB） |

## 构建与渲染类

| # | 现象 | 根因 | 处置 |
|---|---|---|---|
| 16 | 导图 checkbox 裸露、点击放大失效 | 改样式时整体替换 CSS 段，把 `.mmzoom-t{left:-9999px}` 与 `:checked ~` 全套冲掉了 | CSS 只做增量追加；改完渲染验证开合 |
| 17 | 自检 `sections 0` 但文件里有章节 | `h.count("<section>")` 数不到 `<section id="s1">` | 改 `len(re.findall(r"<section[\s>]", h))` |
| 18 | 注册表枚举多出 1 项 | 正则把 docstring 里的示例 `XxxSpec("id", ...)` 也算进去 | 改 `ast.walk`，只认真实 `ast.Call` |
| 19 | 导图中心节点被两侧卡片压住 | 卡片边界按 `CX-gap` 算，没让开中心节点半宽 | `left_edge = CX - cw/2 - gap` |
| 20 | chip 文字溢出圆角框 | 中文字宽估算偏小（按 1.0em） | CJK 按 1.06em，内边距 26px |

## 项目设计限制（不是坑，要写进边界思考）

| 现象 | 本质 |
|---|---|
| 本地素材绝对路径被拒，报 `no valid local video materials` | `resolve_path_within_directory()` 限制在 `storage/local_videos`，防目录穿越 |
| 传完整音色名以外的值直接失败 | 枚举严格匹配，不做模糊查找 |
| 同一时刻只能跑一个任务 | 单 worker 串行设计，不是并发 bug |
| 首次运行极慢 | 拉模型 / 下载素材，不是卡死 |

**归类纪律**：这类写进「边界思考」并注明"项目设计如此"，不要混进踩坑表 —— 混进去会让读者误判项目质量。

## 排查顺序（遇到新问题）

1. 看**实体**不看日志：`site-packages` 条目数、进程是否存在、文件是否真生成
2. 一次只改一个变量，改完重试一次
3. 三次失败就换路径，别死磕同一条命令
4. 记录时写清「现象 / 根因 / 处置」，把根因归类（设计 / 环境 / 参数）
