# 截图取证

截图是这个技能里唯一无法被文字替代的证据。两条纪律：

1. **必须真实** —— 跑不通就写"未获取"，不画示意图
2. **必须可追溯** —— 每张图注写清来源（哪个 URL / 哪条命令）

---

## 两类截图，作用不同

| 类型 | 拍什么 | 证明什么 |
|---|---|---|
| 静态面板 | 首屏、设置区、结果页 | 界面确实长这样，功能确实存在 |
| 使用流程实拍 | 按真实操作顺序，每步一张 | 这条链路确实能走通 |

只拍静态面板，读者会怀疑"这是不是 demo 图"。加上流程实拍，等于把操作过程开源了。

---

## 自动截图脚本

```bash
python scripts/shot_pages.py \
  --api http://127.0.0.1:8080/docs \
  --webui http://127.0.0.1:8501 \
  -o shots/ --tall 2800
```

脚本已处理的四件事：

| 问题 | 处置 |
|---|---|
| playwright 自带浏览器 build 号不匹配 | 自动探测系统 Edge / Chrome，`executable_path` 回退 |
| 首屏被引导浮层遮挡 | 依次尝试多个关闭选择器 |
| Streamlit 只有内部容器滚动，`full_page` 只截一屏 | 视口开到 `--tall` 高度一次装下 |
| Swagger 端点默认折叠 | 循环点开全部 summary（点 2–3 轮，展开后布局会变） |

常用参数：

```bash
--tall 2800        # 大视口，Streamlit 整页
--cut "300-2100"   # 按 y 区间裁切
--only webui|api   # 只截其中一个
```

## 流程实拍怎么做

原则：**像真实用户一样操作，不要为了好看而跳步**。

```python
# 每完成一步立刻截图，别攒到最后
await pg.fill('textarea[aria-label="视频脚本"]', script)
await pg.keyboard.press("Control+Enter")     # Streamlit 必须提交，否则下步重跑会清空
await pg.screenshot(path="shots/step-02-script.png")

await pg.click('button:has-text("生成视频")')
await pg.wait_for_timeout(1500)
await pg.screenshot(path="shots/step-03-submit.png")
```

每条流程图的图注格式：

> 图 4-2 脚本与关键词填写完成后的界面状态（来源：本地 WebUI `http://127.0.0.1:8501`）

写清"这一步做了什么"+"状态如何"，读者能对上号。

## 控件点不动怎么办

三类常见情况：

### 1 非标准下拉（分组选择器）

```python
# 点不开、click 超时、选项不在 DOM 里
```

处置：改走项目官方配置项，重启生效，并在文章里说明绕行原因。

```toml
# config.toml
video_source = "local"    # UI 上那个「视频来源」选不中，改配置
```

**这是有价值的记录**：读者遇到同样问题能直接抄。

### 2 按钮被底部栏遮挡

```python
# locator.click() 反复超时
await pg.evaluate("""() => {
  const b = [...document.querySelectorAll('button')].find(x => x.innerText.includes('生成视频'));
  b && b.click();
}""")
```

按文本找元素直接调 `.click()`，比 locator 稳定。

### 3 元素 testid 拿不到

`[data-testid="stVerticalBlockBorderWrapper"]` 返回 0 个 —— testid 随框架版本变化。

处置：不依赖 testid。整页大视口截图 + 按标题纵坐标裁切：

```python
pos = await pg.evaluate("""() => {const o={};
  document.querySelectorAll('h1,h2,h3,h4').forEach(e=>{
    const t=(e.innerText||'').trim();
    if(t) o[t]=Math.round(e.getBoundingClientRect().top+scrollY);});
  return o;}""")
```

拿到 y 坐标后按区间裁。

## 图片入 HTML 的三条约束

1. **base64 内嵌**，不出外链（单文件可离线打开）
2. **PNG 量化到 192–256 色**，截图类接近无损，体积降约 60%
3. **长图限高**，Swagger 展开后上万像素的图用 CSS 限制显示高度，不裁原图

```css
.shot img.compact{max-height:520px;width:auto;max-width:100%;
  margin:0 auto;object-fit:contain;background:#fff}
```

```python
im.convert("RGB").quantize(colors=192, method=Image.MEDIANCUT, dither=Image.NONE)
```

实测：42KB→15KB / 58KB→21KB / 95KB→35KB。

## 图注规范

| 项 | 格式 |
|---|---|
| 编号 | `图 <章>-<序>`，与章节对齐 |
| 说明 | 这张图证明了什么（不是"界面截图"） |
| 来源 | URL / 命令 / 文件路径 |

反例：

> 图 3 界面

正例：

> 图 3-1 首屏任务面板：左侧表单、右侧状态区（来源：本地 WebUI 8501 端口，视口 1500×2800）

## 交付前验图

```python
bad = await pg.evaluate(
    "() => [...document.images].filter(i=>!i.complete||!i.naturalWidth).length")
assert bad == 0
```

内嵌失败时图片是空白块，`naturalWidth` 为 0 —— 这是唯一可靠的检测方式，肉眼看缩略图容易漏。
