交付不是终点，是换考卷。发布会比谁走得好，交付之后比谁退得少、谁半年后还开机。

## 篇幅怎么砍到 572

1. 钩子只留三句：场景 → 事实 → 反差。删掉所有「我记得那天」式铺垫。
2. 每幕只留一个论点 + 一个数据包 + 一句金句，不并列第二组证据。
3. 三座大山用「通俗讲 / 严谨讲」两行对照，不做第三层解释。
4. 行动号召收缩成一句三连问，不回扣第二遍背景。
5. 图注不进正文（画进图片底带），省 20-70 字配额。

## 可复用点

- **「换了考卷」这个比喻**可迁移到任何「从 demo 到量产」的事件（大模型、自动驾驶、消费电子）。
- **「预收不是收入」**这句是财务口的多空分界线，遇到预售型公司直接可用。
- **三座大山三板斧**：能源、供应链、数据。硬件类选题的通用卡点清单。
