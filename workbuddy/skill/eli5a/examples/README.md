## 怎么用这套样例

### 1. 看成品长什么样

直接在浏览器打开 `qiyuan-demo.html`。重点看四处：

- 标题**单行**不折行（`两万块，机器人真发货了`）
- 章节是**编号徽章 01/02/03/04 + 论点式短名**，虚线上边，编号即递进
- 每张图底部有一条深蓝底带，**左边是图注、右边是品牌水印**，同一行
- 结尾是 04「一句话带走」的居中金句，**没有品牌口号行**

### 2. 复用骨架

```bash
cp examples/qiyuan-draft.html draft.html
# 改标题、改正文、保留 <img src="{{IMGn}}"> 结构
python scripts/build.py --src draft.html --out 成稿.html \
  --img img1.png img2.png img3.png img4.png \
  --cap "图注1" "图注2" "图注3" "图注4"
```

`build.py` 会输出 4 张 `成稿_imgN.jpg`（发布时后台上传用）和一份校验报告。

### 3. 复现这篇样例

`qiyuan-demo.html` 里的 4 张图已 base64 内联，不需要原始素材就能直接看。

要重新生成，需要准备 4 张图（3 张场景图 + 1 张 Pillow 直排示意图），然后按上一条命令跑 `build.py`。

## 三篇的写法差异

| | qiyuan | roadster2 | deepseek |
|---|---|---|---|
| 事件类型 | 产品交付 | 技术演示 | 服务故障 |
| 角度 | 现实型（换考卷） | 反差型（能买的不会飞） | 原理型（后厨占灶台） |
| 每幕结构 | 论点 + 数据包 + 金句 | 观察 → 追问 → 升维 | 现象 → 原理 → 商业模式 |
| 收束 | 三年后它还在 | 你只看了热闹 | 不是笨，是太多人同时点单 |

**共同点**：四幕以内、每幕一个论点、论点必落回具体部件或场景、结尾一句能带走。
