# 微信兼容红线与版式参数

## 红线表

| 禁用 | 原因 | 替代 |
|---|---|---|
| `<script>`、`on*=` 事件 | 微信剥离 | 不需要交互 |
| `<style>` 块、class、id 选择器 | 微信过滤 | 样式全内联在 `style` 属性 |
| 表单元素（input / radio / checkbox） | 微信过滤，tab 切换不可靠 | 上下并列的左边框卡片 |
| 外链图片 | 必须 base64 内联 | `data:image/jpeg;base64,...` |
| SVG、`position`、CSS 渐变 | 渲染不稳定 | `border` / `background` 纯色 |
| `<br>` 用于标题换行 | 微信渲染不一致 | 标题一律单行 |
| HTML 实体 `&mdash;` `&#9670;` | 源码模式兼容不稳 | 用字面字符 `—` `◆` `·` |

**判定标准**：粘进公众号源码模式后，视觉效果与本地浏览器一致。

## 分隔与强调

- 分隔 → `border-top:1px dashed #8fb9d6`，不用实体编码
- 强调 → `<b style="color:#0b3d63;">`
- 引用 → 左边框 3px + 浅蓝底

| 项 | 值 |
|---|---|
| 外底 | `#bcdcf2` |

| 描边 | `#8fb9d6` |
| 主色 | `#0b3d63` |

| 纸面容器 | `max-width:677px`、`padding:36px 26px`、`border-top:3px double #0b3d63` |

字体栈：`'Noto Serif SC','Songti SC',STSong,SimSun,serif`（微信端会回落到系统宋体，不要指望 web font）。

## 图片底带规范

底带高 84px，压在图片底部：

- **左**：图注（≤12 字，白色 22px，过长自动缩字号到 12px 下限）
- **右**：品牌水印「资深架构师 李福春」（白色 22px）
- 背景：`fill=(11,61,99,235)`，即 `#0b3d63` 带 92% 不透明度

底带同时承担两个职责：**覆盖 ImageGen 自带的平台水印**，以及**承载图注**。所以 Pillow 自绘画布底部必须留 ≥100px 空白，否则底带会压住卡片内容。

## 发布时的一步

微信正文不接受 base64 图片。`build.py` 会在工作目录另存 `成稿_img1.jpg`…`成稿_imgN.jpg`，发布时在公众号后台上传这些 JPG，替换对应位置的图即可。版式是内联 CSS，源码模式整段粘入不会塌。
