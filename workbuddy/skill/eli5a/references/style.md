# 卡兹克风格速查 + ELI5 三段式

## 禁用标点

| 禁用 | 替代 |
|---|---|
| 冒号「：」 | 断句或逗号，或直接换行 |
| 破折号「——」 | 句号断成两句 |
| 双引号 `""` `“”` | 用「」 |

## 禁用词（AI 味最重的 12 个）

说白了、意味着什么、这意味着、本质上、换句话说、不可否认、综上所述、首先/其次/最后、值得注意的是、不难发现、在当今、随着。

这些词一出现，读者立刻知道是 AI 写的。**写完必须 grep 一遍**：

```bash
grep -nE "说白了|意味着什么|这意味着|本质上|换句话说|不可否认|综上所述|首先|其次|最后|值得注意的是|不难发现|在当今|随着" 成稿.html
```

## 推荐口语

不是哥们、你想想看、坦率的讲、其实吧、我有时候觉得、说真的、太离谱了、你敢信、回到 xxx 这块、说起来你可能不信。

**用法**：一段里最多出现一次，多了就腻。它负责把「讲解」拉回「聊天」。

## 情绪标点

「。。。」「？？？」可在关键节点各用一次，制造停顿与反问。**全文各一次，不要第二处。**

## 节奏

- 短句推进。一句话能独立成段就独立成段，不要为了段落整齐把三句并成一段。
- 金句单独成段并加粗，前后各留一段白。
- 不加 markdown 小标题，用编号章节断幕。

## ELI5 三段式（通俗与严谨并列）

同一件事写两遍，上下相邻，不用按钮切换（微信会过滤表单元素）：

```html
<div style="border-left:3px solid #c8a03c;background:#fffaf0;padding:12px 16px;margin:16px 0 0;font-size:15px;line-height:1.8;text-align:justify;color:#5a4a20;"><b style="color:#0b3d63;font-weight:700;">通俗讲</b>　吹饱气球松手，气往后跑，球往前冲。</div>
<div style="border-left:3px solid #0b3d63;background:#dceefb;padding:12px 16px;margin:12px 0 0;font-size:15px;line-height:1.8;text-align:justify;color:#1f2d3d;"><b style="color:#0b3d63;font-weight:700;">严谨讲</b>　动量守恒，向后喷射的压缩空气产生反向推力，推力超 80 千牛。</div>
```

金棕左边框 = 通俗，深蓝左边框 = 严谨。读者从上往下读，两版都能看到，不点也能看全。

**比喻选择**：气球（作用力反作用力）、吸尘器（压力差吸附）、便利店 vs 现做后厨（即时响应 vs 占用资源）、菜谱 vs 餐厅（模型 vs 服务）。比喻要能一句说完，说不完就换一个。

## 开篇钩子三选一

1. **具体场景**：一台车，倒挂着贴在天花板上，还在跑。我第一反应是假的吧。
2. **反常识设问**：给你三百字讲清它凭什么挂得住，你讲得清吗。
3. **时间冲突**：九年前亮相，所有人等交付。九年后它飞起来了，可你能订的那台还是不会飞。

禁止宏大叙事开场（「随着人工智能的发展……」是典型 AI 开场）。

## 收束

最后一幕固定叫「一句话带走」，19px 加粗居中金句 + 一句行动号召。行动号召回扣开头的场景或意象，形成闭环。

**结尾不放品牌口号行。**
