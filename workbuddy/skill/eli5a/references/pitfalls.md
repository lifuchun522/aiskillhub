# 踩坑清单

按**返工代价**分级。P0 = 发布出去才发现就废了；P1 = 要重跑一遍。

## P0

### 1. 用 `<style>` 块写样式 → 粘进微信全丢

微信编辑器会过滤 `<style>` 块和 class/id 选择器。**样式必须全内联在 `style` 属性里**。本地浏览器看着好好的，粘进去版式全塌。

判定标准不是「本地渲染对不对」，而是「粘进源码模式还对不对」。

### 2. 用表单元素做 tab 切换 → 微信过滤后只剩一堆文字

radio + `:checked` 在浏览器里切换正常，粘进微信后 `<input>` 被过滤，切换规则失效，两个面板同时显示。

**替代方案**：直接上下并列的左边框卡片，金棕=通俗、深蓝=严谨。读者从上往下读，不点也能看全。

### 3. 外链图片 → 微信不接收

base64 内联是唯一可靠的。但**发布时微信正文也不接受 base64**，所以必须同时另存独立 JPG，让用户在后台上传替换。**两件事都要做，缺一个都不完整。**

### 4. ImageGen 图里放中文 → 100% 乱码

图内文字一律走 Pillow 直排（simhei / Noto Sans CJK）。出图的 prompt 里必须写 `no text`。

## P1

### 5. 画布底部不留白 → 84px 底带压住卡片

Pillow 自绘示意图时，底带会盖住图片最下面 84px。卡片布局没留出这段，底边内容就被压掉。

**规则**：画布底部留 ≥100px 空白。改卡片高度时要同步改画布高度（踩过一次：卡高 320→230，画布忘了同步从 520→440，卡片下半截留白过大）。

### 6. 图注占字数 → 1000 字上限被图注吃掉

页面里放 6 条图注大约吃掉 40-70 字配额。

**规则**：图注不进页面，画进图片底带。页面字数只算正文。

### 7. 章节名写成名词短语 → 读者看不出递进

「关于交付」「三座大山」这类名词短语没有论点，四幕之间看不出逻辑推进。

**规则**：章节名必须是论点句（「交付之后，比的不一样了」），≤10 字，禁「讲讲/聊聊/白话讲讲」前缀。

### 8. 标题用 `<br>` 换行 → 微信渲染不一致，且不方便传播

标题必须单行、≤12 字。**渲染后用 `h1.clientHeight / lineHeight` 量一遍**，取整必须 = 1。

### 9. 双水印叠加 → 底带盖了两层

图片已经跑过一次 `build.py`（带上底带），再跑一次会叠两条。

**规则**：已带底带的图用 `--no-watermark`。

### 10. 只凭「调用没抛异常」就报成功

字数、标签开闭、外链、图X编号、口号行、`<br>` 残留——每一项都要跑正则实检，不能凭印象。

**最危险的一处**：`http` 检测。页面里如果残留任何 `http` 字符串（哪怕是注释里的），就说明有外链没内联干净，微信端图全破。

### 11. 占位符只写 `{{IMG1}}` 没写 `src="{{IMG1}}"` → 图全变细线

`build.py` 是把占位符替换成 data URI 字符串。如果模板里写的是 `<img {{IMG1}} ...>`，

替换后就变成 `<img data:image/jpeg;base64,... style="...">`——**data URI 被当成了一个无值属性，`src` 根本不存在**。

页面渲染出来的不是破图图标，而是**一条 2px 高、带描边的细线**，肉眼极容易误判为「分隔线」。

而 `img` 计数、`data:` 计数、外链布尔全部正常，三张图都在，校验全绿——**只有实渲染截图能抓到**。

**规则**：

- 模板里必须写 `<img src="{{IMG1}}" ...>`
- `build.py` 输出里增加一项 `img 缺少 src 属性`，必须为 0
- 交付前必须看**至少一张包含图片的实渲染截图**，不能只跑计数类校验

## 两条元经验

1. **验证器报错时，先问「是稿子错了，还是尺子错了」。** 有过一次字数脚本把图注算进正文导致误报超标，改的是尺子不是稿子。
2. **最该持续更新的是这一节，不是「正确做法」那一节。** 前者是经验，后者是常识。
