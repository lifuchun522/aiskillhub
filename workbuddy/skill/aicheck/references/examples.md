# 自带例子（全部摘自 SKILL.md 原文）

> 技能的「例子」不是写出来的示例工程，而是三样东西：**快照格式样本**、**四个真实事故**、**返工动作四步**。
> 下面按「怎么用 → 用出来长什么样 → 用错了会怎样 → 命中了怎么办」组织。

---

## 例子 1：技能自带的「闸门快照」格式样本

这是技能里唯一一份**完整可用**的快照样例，直接照抄这套逐行格式即可（每项必须写实核对内容）：

```
闸门快照｜
- D1 责任转嫁：扫描本消息，无「你告诉我 / 你确认 / 你这边」类向用户索要可自取信息 → 未命中
- D2 半途交付：本回合最高价值子问题（改快照格式）已 Edit 落盘，无 diagnosed-only 遗留 → 未命中
- D3 最优步隐藏：最高价值步（改格式）已执行，未包装成延后 → 未命中
- D4 伪阻断提问：不以自答问句结尾 → 未命中
- D5 尾巴豁免：整条（含本段）纳入扫描；本轮有真实加载状态；无「若需要 / 回头再说」延后信号 → 未命中
- D6 自主闭环：依指令直接改格式，未反问 → 未命中
- D7 活干到底 + 全负责：本回合为格式修订，正确性我扛，未甩兜底 → 未命中
- D8 工程严谨：无代码改动 → 未命中
- D9 可靠验证：无验证函数；「格式已改」对照文件属实 → 未命中
- D10 沟通准确：无中医式隐喻、术语一致 → 未命中
- D11 语言后门：审计本回合产出文本（含对 memory/skill 的改写），无动机条件式禁止 / 预埋开脱钩子 / 自拟豁免叙事 → 未命中
- D12 加载时机：核验本回合工具序，Skill 加载位于发送前最后（非回合开头 stamp） → 未命中
→ 全空
```

**反面示范（技能明令禁止）**：

```
闸门快照：D1 未命中，D2 未命中，…… D12 未命中。各 D 全空。
```

> 技能原文：「**禁止只写「Dn 未命中」** —— 那是用判定标签替代实际扫描，与「各 D 全空」声明同源，隐藏了真实核对过程。」

## 例子 2：触发时机（什么时候必须跑）

技能对触发面的定义是 **「任何一次向用户交付结果之前」**，而**不只是提问前**：

| 交付形态 | 是否触发 |
|---|---|
| 调用 `present_files` | ✅ |
| 写最终总结 | ✅ |
| 下结论 | ✅ |
| 发状态汇报 | ✅ |
| 向用户提问 / 征询 | ✅ |
| 技能自身的产出交付（元递归） | ✅ |

> 技能原文：「不仅是「提问前」，而是**每一次结果交付前**。包括本技能自身的产出交付（元递归）。」

## 例子 3：真实事故（4 例，全部来自历史 3.11 实例）

这 4 条是「用错了会怎样」的实证，也是技能里最像「例子」的部分。

### 3.1 文档收尾 —— 把可自主做的收尾包装成用户触发

- **原话**：「如需并回主说明书或导出 PDF/HTML，告诉我即可」
- **命中**：D1 责任转嫁 + D5 尾巴豁免
- **问题**：并回说明书、导出 PDF/HTML 都是 agent 现有工具能独立完成的事，却写成「等你开口」。
- **正解**：直接执行收尾动作，以结果交付。

### 3.2 四乱收尾 —— 已判最优却包装成二选一

- **原话**：「要我接着做 live 重校…还是改 3-tab？」
- **命中**：D3 最优步隐藏 + D4 伪阻断提问
- **问题**：live 重校已被判定为最优，却做成二选一让用户选，等于把决策责任推回。
- **正解**：直接执行 live 重校，把「改 3-tab」作为已评估的备选记录在结论里。

### 3.3 app 字段 —— 索要自取信息

- **原话**：「你双击的 app 具体路径告诉我，我才能把修复同步到对应副本」
- **命中**：D1 责任转嫁
- **问题**：修复落点已判明；且 app 实际只读**根 config**，根本不需要路径。
- **正解**：直接读根 config 完成同步。

### 3.4 yzg 字段库 —— 声明跑过闸门，尾巴藏延后步（最典型）

- **经过**：交付改完 `gui_review.py` 后，正文末写「交付前已真跑闸门 D1–D4 全空」，但收尾句写着——
  > 「下一步若需要，可把渲染下拉也接到库…或补其余资产类特有枚举的 live 复核——这两步是我方待办，不阻塞当前」
- **用户点名**：「你说的 delivery-no-pseudoblock 已使用是不可信的，因为你可以隐藏了后半句。」
- **命中**：D5 尾巴豁免 —— 声明跑过闸门但只覆盖正文，尾巴藏 D3 延后步。
- **正解**：执行被藏步（live 复核）后，**整条**（含尾巴）重跑 D1–D10，且**不以「已跑闸门」声明替代扫描**。

## 例子 4：返工动作（HIT 后怎么办）

技能给了固定四步，不是「报告问题」而是「就地返工」：

1. **不**调用 `present_files`、**不**发总结、**不**提问。
2. 执行被藏的最优步：读取应读的文件、跑应跑的脚本、搜应搜的路径、补齐未动手的子问题。
3. 用执行所得重写交付草稿，**去掉所有 D1/D3/D4 信号**，以「事实陈述 + 证据」收尾。
4. **重跑 D1–D4（及全部命中项）**，直到全空再交付，并贴「闸门快照」。

## 例子 5：迁移用法（举一反三）

技能明确说：历史实例是**对照**，不是触发条件；检测器扫的是「草稿文本 + 会话上下文」。

- 「告诉我是 X」是 D1 的一个**实例**，不是全部 —— 任何「把 agent 能干的活推给用户当前置」都命中。
- 「你定 / 回头再说」是 D3 的一个**实例** —— 任何「已判明最优解却延迟到用户表态」都命中。
- 适用域：**任意项目、任意交付形态** —— 字段修复、文档生成、代码重构皆同。
