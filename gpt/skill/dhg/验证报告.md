# dhg 1.0.0 验证报告

验证日期：2026年10月18日。范围为本技能、计数脚本、模拟写作场景和两篇既有文章的机械检查；不把场景通过解释为所有未来文章都正确。

## 1. 结构与程序验证

- 使用 skill-creator 的 `quick_validate.py`：通过名称、YAML元数据及未完成模板检查。
- `python -m unittest discover -s tests -v`：11项通过。
- 覆盖总字数1500/1501、单段100/101、多行回答、回答与个人思考分开计数、链接与图片替代文本、标点英文、空稿、缺图、远程图片未验证状态、自定义会后标签、离开会后节后的防误报。
- 初次测试先因脚本尚不存在而失败，写入脚本后通过。独立试写发现会后自定义标签漏检后，新增两项回归测试，先复现失败，再修复并重跑11项。
- 图片检查仅证明路径存在，不证明格式正确或图内文字准确；远程图片保持未验证提示。

| 场景 | 实际结果 | 覆盖边界 |
