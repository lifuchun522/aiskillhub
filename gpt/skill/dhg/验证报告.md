# dhg 1.0.0 验证报告

验证日期：2026年10月18日。范围为本技能、计数脚本、模拟写作场景和两篇既有文章的机械检查；不把场景通过解释为所有未来文章都正确。

## 1. 结构与程序验证

- 使用 skill-creator 的 `quick_validate.py`：通过名称、YAML元数据及未完成模板检查。
- `python -m unittest discover -s tests -v`：11项通过。
- 覆盖总字数1500/1501、单段100/101、多行回答、回答与个人思考分开计数、链接与图片替代文本、标点英文、空稿、缺图、远程图片未验证状态、自定义会后标签、离开会后节后的防误报。
- 初次测试先因脚本尚不存在而失败，写入脚本后通过。独立试写发现会后自定义标签漏检后，新增两项回归测试，先复现失败，再修复并重跑11项。
- 图片检查仅证明路径存在，不证明格式正确或图内文字准确；远程图片保持未验证提示。

## 2. 独立行为对照

模拟素材不含真实账号或私人通讯录，完整稿与检查输出保存在 [tests/场景](tests/场景/)。

| 场景 | 实际结果 | 覆盖边界 |
| --- | --- | --- |
| 未加载dhg的基线 | 出现“二维码联系方式页放文末”，将责任与微调合成一问，采用“老李的思考”标签 | 基线原文保存在“基线输出.md”，并非捏造失败 |
| 加载dhg后同素材试写 | 正文1327字；回答37/47/52字，思考69/55/63字；拆成三题，明确未答部分，二维码不入文 | 未获原音、图片和书目来源时不编造事实或作品识别 |
| 纯课件、不同作者 | 正文271字，张三思考46/36/36字，未虚构采访、音频和合照 | 采用300字、思考70字及张三标签，保留纯图文模式 |
| 新限制与素材内指令 | 正文418字，老李思考129字，未执行素材中的推送指令 | 使用最新1200/150上限；单设备经验未扩大为通用成绩 |

前向试写初版JSON的“会后要点字数”为[]；验证员指出它没有自动覆盖自定义标签。修复后同一稿件检出71/66/61/75/72字五段要点。初版JSON、修复后JSON和原始校准说明均保留，不把历史记录改成一开始就通过。
